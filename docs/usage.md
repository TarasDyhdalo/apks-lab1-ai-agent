# Використання

## Запуск агента

1. Відкрий репозиторій у VS Code з увімкненим Copilot Chat.
2. У чаті виконай команду `/init-project`.
3. Агент послідовно перевірить git, створить структуру, налаштує build і тести, додасть GitHub Actions та виконає фінальну перевірку.
4. Якщо крок завершиться помилкою, агент зупиниться. Виправ причину і повтори відповідний prompt.

## Запуск проєкту локально

На Linux або macOS виконай:

```bash
./ci.sh
```

На Windows виконай:

```bat
ci.bat
```

Скрипти створюють `.venv`, встановлюють `pytest`, запускають тести, пакують `src/hello` у `build/hello.pyz` і перевіряють артефакт.

Після успішної збірки запуск артефакту:

```text
python build/hello.pyz
```

Очікуваний результат:

```text
Hello, World!
```
