# Лабораторна робота №1: AI-агент для автоматизації розробки та CI/CD

- **ПІБ:** Дигдало Тарас
- **Група:** КІ-402
- **Варіант:** 2 (Python, venv + скрипт запуску, pytest)

## Опис
Спеціалізований AI-агент (GitHub Copilot) для генерації, складання,
тестування та перевірки кросплатформного проєкту Hello World.

## Короткий опис

Агент у `.github/agents` оркеструє skills і prompts для створення кросплатформного Python Hello World, локальної перевірки через `venv` і `pytest`, пакування у zipapp та запуску CI на трьох операційних системах.

## Запуск агента

У Copilot Chat виконайте `/init`. Детальна інструкція міститься в [docs/usage.md](docs/usage.md).
